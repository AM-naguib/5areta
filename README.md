# 5areta — إدارة المحل

واجهة عربية RTL بسيطة لإدارة المحل من الموبايل والكمبيوتر بدل الورق أو الشيتات.

## منطق الحساب

- **ربح المحل** = الإيراد − تشغيل المحل − الصنايعي
- **صافي الداخل للخزنة** = ربح المحل − السحب الشخصي من دخل اليوم
- **رصيد الخزنة الحالي** = الرصيد الافتتاحي + مجموع صافي الداخل للخزنة − سحوبات الخزنة الرئيسية

> سحب مبلغ من الخزنة الرئيسية (مثل جمعية أو التزام كبير) لا يغيّر ربح المحل؛ هو فقط يقلل رصيد الخزنة.

## المميزات

- Mobile-first و RTL.
- تسجيل يومي سريع.
- ملخص شهري للإيراد والربح والعملاء ومتوسط الزبون.
- فصل تشغيل المحل، الصنايعي، والسحب الشخصي.
- إدارة سحوبات الخزنة الرئيسية بشكل مستقل.
- حفظ محلي على الجهاز بدون سيرفر.
- Backup / Restore بصيغة JSON.
- تصدير السجل CSV.
- PWA قابلة للتثبيت على الموبايل والعمل Offline بعد أول تحميل.

## تشغيل محلي

أي web server بسيط يكفي، مثل:

```bash
python -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## GitHub Pages

المشروع Static ومجهز للنشر عبر GitHub Pages من خلال Workflow داخل `.github/workflows/pages.yml`.

## الخطوة التالية المقترحة

للاستخدام على أكثر من جهاز بنفس البيانات، أضف Backend مثل Supabase (Auth + Postgres). الواجهة الحالية منفصلة عن التخزين بحيث يمكن نقل البيانات من localStorage إلى API لاحقًا بدون إعادة تصميم التطبيق.
